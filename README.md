# SuperPower Copy and Translate

SuperPower Copy and Translate is an advanced Android application designed to break down language barriers and enhance productivity. It allows users to effortlessly capture text from any screen on their device, perform instant translations, and manage copied content with a sleek, futuristic interface.

## 🚀 Features

*   **Universal Screen Copy**: Capture and extract text from any app or screen using the underlying Media Projection API and ML Kit OCR.
*   **Instant Translation**: Seamlessly translate captured text between multiple languages. Supports both on-device (offline) and cloud-based translation.
*   **Floating Overlay Widget**: A non-intrusive floating button ensures the tool is always just a tap away, without disrupting your workflow.
*   **"Chaos Mode"**: A unique, high-energy UI mode for users who prefer a more dynamic visual experience.
*   **Cyber Tech Aesthetics**: Designed with a modern "Cyberpunk" inspired UI, featuring dark modes, neon accents, and glassmorphism effects.

## 🛠️ Tech Stack

*   **Language**: Kotlin
*   **Architecture**: MVVM (Model-View-ViewModel)
*   **UI**: XML Layouts & Custom Views (Transitioning to deeper Jetpack integration)
*   **ML & AI**: Google ML Kit (Text Recognition, Translation)
*   **Background Processing**: Android Services & Coroutines

## 📦 Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/AgamPandey133/SuperPower_CopyNTranslate.git
    ```
2.  Open the project in **Android Studio**.
3.  Sync Gradle project with files.
4.  Run the application on an emulator or physical device.

## 🔒 Privacy

This app uses the `MediaProjection` API to capture screen content solely for the purpose of text extraction and translation initiated by the user. No screen data is stored permanently or transmitted to unauthorized servers.
